# Github rules

## Pushing rules

- This project has a github repo and you should use the new branch for each commit and push because i restrict direct push to the main branch in github

## GitHub review delivery

After a feature's acceptance checks pass and its handoff is marked complete:

1. Confirm the handoff states the completed acceptance checks, changed files,
   verification evidence, known limitations, and exact next task.
2. Commit only that feature's changes on a new branch; never push directly to
   `main`.
3. Push the branch to GitHub and open a pull request for review. Include the handoff
   note or link to it in the pull-request description.
4. Only then report the feature as complete and ready for review. Do not merge the
   pull request without the repository owner's approval.
